# Encryption Program Python
### A text-based encryption-decryption program using randomly generated keys.
## What Is This Project?
This was one of my first Python projects, being created during my first year of a-levels. This was created at the time to improve my python skills and familiarise myself with dictionaries. Version 2.0 reworks the program to be more readable and efficient, implementing what I have learned since first writing the program.
## How To Use
When starting the program, type 'encrypt' or 'decrypt' to begin. Any text entered is then encrypted / decrypted and printed. Further commands include 'printencryptionkeys', 'printdecryptionkeys' and 'printkeys' which are used to print the randomly generated keys, 'newkeys' which generates new encryption and decryption keys, 'changemode' which returns to the start of the program requiring 'encrypt' or 'decrypt' to be input, 'stop' which terminates the program and 'help', providing this information within the program.
